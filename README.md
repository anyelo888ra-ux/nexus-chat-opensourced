# NexusChat 🚀

NexusChat es una plataforma de mensajería de código abierto y descentralizada inspirada en Discord, diseñada para funcionar de forma ligera en navegadores web.

## 🌟 Características
- 🎨 **Interfaz al estilo Discord:** Diseño oscuro, lista de servidores, canales de chat y avatares.
- 🛠️ **Creación de Servidores:** Los usuarios pueden crear sus propios servidores al instante sin configurar bases de datos complejas.
- 🔗 **Conexiones P2P:** Transmisión de mensajes en tiempo real entre usuarios mediante protocolo WebRTC (PeerJS).
- 🔓 **Open Source:** 100% libre de modificar y personalizar.

## 🚀 Despliegue en GitHub Pages
Para alojar NexusChat en tu propia instancia:
1. Haz un Fork de este repositorio.
2. Ve a **Settings > Pages**.
3. Selecciona la rama `main` y guarda los cambios.
